# EdgeOne 作品集上线指南

核对日期：2026-10-28。界面可能称为 EdgeOne Pages 或 Makers；入口名称、免费额度和默认域名策略会变化，操作前对照文末官方文档与当前账号页面。本文针对见页导出的静态作品集，不要求购买云服务器。

## 路径与费用先说明

| 情况 | 建议 |
| --- | --- |
| 只预览作品集 | 本地编辑、导出即可，无需域名或云服务 |
| 想先试部署、不买域名 | 可以验证平台提供的预览地址；先说明访问地域与有效期，不能承诺是中国大陆可长期使用的公开地址 |
| 希望长期分享、国内外都能查看 | 评估自有域名；已有域名就复用，不重复购买 |
| 未备案、希望先上线 | 选择“全球可用区（不含中国大陆）”，以控制台当前要求为准 |
| 希望使用大陆节点 | 先按官方条件完成 ICP 备案，不承诺当天完成 |

截至核对日，官方域名概览说明：含大陆节点项目的系统预览链接有有效期；不含大陆节点项目的默认域名对大陆网络也有限制。因此“有免费托管套餐”不等于“免费默认域名适合永久投递”。向用户提供网址前，在其实际访问网络检查，不要把 401 一律解释为网页出错。[默认域名与加速区域](https://edgeone.cloud.tencent.com/pages/document/175191784523485184)

静态站使用免费套餐时，核对账户当前套餐、用量及费用规则；域名注册和续费另计。不要默认购买 CVM、轻量服务器、云盘、快照、数据库、付费 DNS 或付费 SSL。若用户看到扣费，先查账单产品名称，不能直接归因于此网站。[套餐与用量入口说明](https://edgeone.cloud.tencent.com/pages/document/162936949996421120)

## 1. 准备作品集网站包

1. 内容校对完成后，在编辑器点击“备份资料”，保留可继续编辑的 JSON。
2. 点击“导出网站”，获得独立 HTML。预览图片与链接，检查项目身份、完成状态和公开联系方式。
3. 调用 `scripts/folio.py pack --html "实际导出文件" --out "新的输出目录"`，或手动把导出文件改名为 `index.html` 并压缩。
4. **上传的是 `website.zip`**。打开 ZIP 第一层应直接看到 `index.html`，不能是 `release/site/index.html` 或 `dist/index.html`。不要上传 Skill ZIP、编辑器、资料 JSON、原始简历或证件。
5. 本工具把图片和字体嵌入 HTML；若单 HTML 超过平台单文件上限，先减少图片体积或改为拆分静态资源。不能把不同格式的原图强制拉伸来缩小文件。

直接上传接受已生成的静态产物，不会在平台替你运行构建命令。当前文档支持文件夹、ZIP、单 HTML，入口须在根目录，单文件上限为25MB。以控制台校验提示为准。[直接上传](https://cloud.tencent.com/document/product/1552/127371)

## 2. 创建项目与首次部署

登录腾讯云官方控制台，进入 EdgeOne Pages/Makers，创建项目并选择“直接上传”。填写当前控制台允许的项目名，选择上述适用区域，上传 `website.zip`，点击开始部署。静态导出不需填写 npm 构建命令。

等待构建部署显示成功；打开平台提供的预览入口，记录它是临时预览链接还是正式项目网址。当前文档说明直接上传项目不能原地切换成 Git 集成，日后需要 Git 自动部署时应另建对应项目。[直接上传与后续部署](https://cloud.tencent.com/document/product/1552/127371)

不要因为网站构建成功就结束整个发布流程；自定义域名还需下面的注册/解析/HTTPS状态。

## 3. 域名注册（没有域名时才做）

在腾讯云域名注册页面搜索想用的名字。注册 `example.com` 或 `example.cn`，`www` 是随后配置的子域名，不是另买一个域名。比较首年价、续费价与用途，价格以订单为准，不使用本项目历史购买价格作为其他人的报价。

按官方页面创建实名信息模板并关联。实名资料只在注册商页面提交，不发给 Agent，不放进项目。购买时只选择需要的域名年限；附带服务器、付费解析、付费证书不作为此工作流的必需项。自动续费按用户意愿；禁止转移锁通常可保留，禁止更新锁应确认不会阻碍接下来的 DNS 设置。

用户确认域名和价格后自行支付。随后分别检查域名实名和命名审核状态；不要反复创建重复模板。命名审核目前官方通常说明1—3个工作日，但不能保证具体完成时刻。处于 ServerHold 等禁止解析状态时，先处理注册审核，不靠删除重加 EdgeOne 项目解决。[注册流程](https://cloud.tencent.com/document/product/242/9595)、[实名状态](https://cloud.tencent.com/document/product/242/6707)、[命名审核](https://cloud.tencent.com/document/product/242/58535)

域名审核、EdgeOne 归属验证、ICP 备案是三件不同的事。含大陆区域的备案要求，按[域名与区域说明](https://edgeone.cloud.tencent.com/pages/document/175191784523485184)及当前备案官方流程处理，不提供凭空估计的办理成本和时限。

## 4. 绑定域名与添加 DNS

推荐先把 `www.example.com` 设为主访问地址。在项目的“域名管理”添加该域名，关联生产环境。

若页面要求归属验证，逐字段读取**当前项目返回的**主机记录、类型、记录值，去域名的权威 DNS 服务商处填写。通常可以在 DNSPod 管理腾讯云域名；以域名实际 NS 托管位置为准，不能只因购买在腾讯云就断定 DNS 必在 DNSPod。

以下是字段含义示意，不是可直接复制的真实凭据：

| 用途 | 主机记录示意 | 类型 | 值从哪里取 |
| --- | --- | --- | --- |
| 归属验证 | 控制台给出的验证主机 | 按界面，常为TXT | 当前归属验证弹窗 |
| 网站访问 | www | CNAME | 当前项目该域名行显示的 CNAME |
| 证书委派验证（需要时） | 控制台给出的证书主机 | 按证书界面 | 当前证书申请弹窗 |

DNSPod 的主机记录通常填相对主域名的部分；有些服务商要求完整域名，提交后核对最终完整记录名，避免重复拼接 `example.com`。TXT 与 CNAME 的目标不同，不可把归属验证记录当作网站访问记录。CNAME目标不要添加 `https://` 或路径，也不要照抄其他用户域名。

等待解析生效，再回项目点击验证/刷新。若 `www` 已有冲突 A/AAAA/CNAME，先确认它是否属于旧业务，得到当前任务范围内的明确授权再替换，不删除无关邮件等解析。根域 `example.com` 若也要访问，需要另行绑定、配置解析并设置主域跳转；只配 `www` 不会自动让根域生效。[站点归属验证原理](https://cloud.tencent.com/document/product/1552/70789)

## 5. 免费 HTTPS 与网站设置

在对应域名的 HTTPS 配置中，选择“申请免费证书”。新网站且 CNAME已生效时，可先选“自动验证”；如需提前签发或界面提示其他要求，按官方指引选择 DNS 委派验证。文件验证只在确实能放置并公开访问验证文件时使用。每种验证都要读该次生成的内容，不能复制历史验证值。

等待证书已部署，并确认 `https://www.example.com` 实际打开正常后，再开启“强制 HTTPS”。HSTS 暂不作为首次上线必选；不为了补齐开关而开启所有高级设置。免费证书由平台管理续签，但依赖相应验证条件继续有效。不能因为“申请中”或“部署中”就声称 HTTPS 已成功。[申请免费证书](https://cloud.tencent.cn/document/product/1552/127407)

网站内容层面核对标题、页面语言、个人署名、图片清晰度、手机布局、链接与二维码。默认 noindex 表示提示搜索引擎不收录，不阻止别人访问和转发；用户希望被搜索发现时，经其确认再移除。没有得到的学历、工作身份、项目状态不得为“美化”而改写。

## 6. 真正完成与维护

完成条件：生产部署成功；所选主域名状态生效；DNS 指向当前项目；HTTPS证书已部署；浏览器访问与手机测试通过。项目默认网址成功不能替代自定义域名检查，HTTPS绿色也不能替代页面内容检查。

记录项目名、主网址、区域、DNS记录用途及证书状态、最后更新时间，不记录口令。后续修改后从编辑器备份并导出，用新 ZIP 在**原项目**创建新部署；先确认是否更新生产环境。需要撤回时使用平台提供的部署切换/回滚能力，以当前控制台为准。

| 现象 | 先检查 |
| --- | --- |
| 首页404 | ZIP根目录有没有 index.html，上传的是不是完整静态产物 |
| 默认网址401 | 当前区域、网络与预览链接有效期，先看官方域名策略 |
| 自有域名打不开 | 注册审核/ServerHold、权威DNS和CNAME、EdgeOne域名状态 |
| 证书申请中 | CNAME是否生效、证书验证方式与详细错误，不反复删除重建 |
| 归属验证成功但仍不可访问 | 它只证明控制权，继续看访问CNAME与HTTPS |
| www能开、裸域不能开 | 根域是否单独绑定并解析，是否配置了有效跳转 |
| 修改没出现 | 上传到哪个环境、生产部署版本、访问的域名、浏览器缓存 |
| 出现费用 | 账单产品及资源ID；将域名续费、托管和旧云盘/快照账单分清 |

超时或明确报错时保留具体状态与错误，再按官方文档定位。不能仅凭“域名命名审核中”认定所有部署异常都是它引起；也不因某次DNS验证成功就忽略注册商暂停解析状态。

# 见页 Folio · 本地作品集编辑器原型 v02

打开 index.html 即可使用，推荐电脑上的 Edge 或 Chrome。此原型不依赖账号、模型 API 或在线字体，不会上传资料。

## 先体验这几步

1. 左侧选择“主题风格”，切换摄影画廊、设计案例、影视项目。主题会改变排版，内容会保留。
2. 回到“页面组件”，点击个人介绍，在右侧改姓名与简介。
3. 选择精选作品或图片画廊，修改项目标题、个人角色、说明，上传真实图片。单张图片最多3 MB，支持 JPG、PNG、WebP、GIF。上传后先进入取景窗口，点击“应用到页面”才加入页面。
4. 用左侧拖动或上下箭头排序；圆点按钮用于显示或隐藏。添加组件可加入视频入口、文字等内容，右侧也支持复制、删除和增删条目。
5. 调整配色、字体组合、留白和进入动效，切换手机预览检查布局。
6. 点击“备份资料”下载含图片的 JSON，之后可通过“导入资料”恢复。
7. 点击“导出网站”下载独立 HTML，双击即可离线查看；同一文件也可交给静态托管服务发布。

初始人物、经历和项目均为虚构示例，图形为程序绘制的示例素材。换成真实内容后，可在个人介绍编辑区关闭“保留虚构示例资料提示”。

## 图片取景

画廊新上传图片默认采用原图比例。需要裁切时，选择方形、竖幅或横幅等画框比例，再拖动图片和调整缩放；可以使用水平、垂直位置滑杆或方向键精调。按原图比例、缩放1倍时没有可移动的多余区域，放大后即可拖动。

证书、海报等内容推荐“原图比例”；如需统一画框，同时保留全部内容，请选择“完整显示 · 不裁切”，允许必要的留白。完整显示时忽略取景位置和缩放。

已添加图片的下方有“调整取景 / 完整显示”，可随时重调。设置跟随图片保存在草稿、JSON备份和导出网页中，原图不会被破坏或重新压缩。取消调整不改变原设置。

设计案例模板的个人头像固定为圆形，取景窗口会显示相同的圆形遮罩；其他图片按所选比例呈现。影视模板的首页封面随屏幕比例调整，请同时检查手机预览。

## 三套不同的编排

- 摄影画廊：巨幅刊头、横向封面、错落项目、两列图集，以图片和留白组织观看顺序。
- 设计案例：个人档案侧栏、大字创作宣言、案例长卡，将角色、说明和作品放在清晰的结构中。
- 影视项目：满幅片头封面与叠字、宽银幕项目、可横向滚动的胶片画廊。

主题共用资料，切换不会清空项目或图片。旧版JSON仍可导入；旧图片可用取景按钮重新调整。

## 已有功能

- 三套主题，七类组件：个人介绍、精选作品、图片画廊、文字叙述、成长经历、视频入口、联系方式。
- 图片上传、项目与经历条目编辑，单列/多列布局选项。
- 组件排序、隐藏、复制和删除；撤销与重做。
- 配色、字体气质、留白和淡入/浮现动效；尊重系统减少动态效果设置。
- 桌面/手机预览，选中页面内容即可定位到编辑区。
- 本机自动保存、JSON 备份恢复、独立网页导出。导出的网页含字体和上传图片，无编辑器依赖。

## 当前边界

本版尚未接入简历 PDF/Word 解析、AI 对话修改、模型 API、云账号或一键发布。导入资料目前只支持本编辑器生成的 JSON，不能直接导入 PDF。

视频组件使用封面与原平台跳转，不存储视频文件。外部视频和项目链接需要联网。编辑状态下点击页面是选择组件，实际链接可在导出的独立网页中测试。

自动保存跟随浏览器、本地文件路径或本地预览地址，换浏览器、移动目录或清理浏览器数据后可能无法读取原草稿；重要资料请下载 JSON 备份。自动保存失败时会明确提示。撤销记录只保留当前会话的最近25步，跨次打开请使用备份。

导出页面默认添加 noindex，用于提示搜索引擎不收录；这不是密码保护。是否公开与使用何种网址，留待发布步骤确认。

字体许可证保留在 assets/licenses。产品名称“见页”为原型工作名，尚未进行商标或域名可用性核查。
